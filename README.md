## Selected Projects

### 01 — WiTrack
**Wireless Motion Tracking Using ESP32 Channel State Information**

WiTrack is an experimental project exploring human movement tracking through wireless signal measurements collected using ESP32 devices.

The system uses a transmitter and a receiver to generate and collect CSI data. The collected measurements can then be processed, analyzed, and visualized to investigate patterns associated with movement.

**Engineering work**
- Setting up ESP32-based transmission and CSI collection.
- Capturing signal measurements and storing experimental data in CSV files.
- Extracting in-phase and quadrature (I/Q) values for analysis.
- Exploring signal visualization and spectrograms using Python.
- Investigating how signal variations can support movement-related analysis.

**Technology:** ESP32 · Python · CSV · Signal Processing · Data Visualization

**Project direction:** Wireless sensing, experimental data collection, and human motion analysis.

## How I Build Software

**Understand before implementing**

I start by identifying the actual problem, understanding existing behavior, and defining what a successful solution should achieve.

I pay attention to how the frontend, backend, database, and external integrations work together rather than treating each component as an isolated piece.
